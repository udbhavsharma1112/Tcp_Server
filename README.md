# Multithreaded TCP Server in C++

This project implements a **multithreaded TCP server** in C++ from scratch using low-level system calls (`socket`, `bind`, `listen`, `accept`, `read`, `write`, etc.). It handles multiple client connections concurrently using POSIX threads (`pthread`).

## 🔧 Features

- Built entirely with system calls (no external libraries)
- Supports multiple simultaneous client connections
- Each client handled in a separate thread
- Graceful shutdown on error
- Lightweight and easy to understand
